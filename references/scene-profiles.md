# 場面プロファイル

同じ表現でも、チャットでは不自然で、仕様書では適切なことがある。場面を先に決め、一般的な「人間らしさ」を押し付けない。

## chat

対象:

- 日常会話
- DM、Slack、Discord
- 短い相談への返答
- コメント

目標:

- 相手がすぐ要点を理解できる
- 形式張った前置きや過剰な承接を減らす
- 元の距離感、丁寧さ、口癖を残す

既定範囲: `minimal`

残すもの:

- 意味のある相づち
- ユーザー本人の略記、顔文字、軽い崩し
- 文脈上必要な謝罪や配慮

減らすもの:

- 「素晴らしい質問です」など内容のない評価
- 「結論から言うと」「詳しく見ていきましょう」の連打
- 回答後の営業的な提案
- チャットに不釣り合いな報告書調

禁止:

- わざと誤字を入れる
- 元文にない感情や馴れ馴れしさを足す
- 丁寧語を勝手にタメ口へ変える

## status

対象:

- 進捗報告
- 日報、週報
- 障害対応の更新
- 会議用の状態共有

目標:

- 時間線、実施内容、結果、未解決事項、次の行動が分かる
- 誰が何を担当したかを保つ
- 渲染や自己評価を減らす

既定範囲: `minimal` または `bounded`

推奨構造:

```text
実施したこと
分かったこと
残っている問題
次に行うこと
```

ただし、元文がこの構造を必要としない短文なら見出しを追加しない。

禁止:

- 数字を「改善した」へ抽象化する
- 未確認の原因を確定する
- 主体を省略して責任を曖昧にする

## technical-docs

対象:

- README
- 設計書、仕様書
- API説明
- 手順書、FAQ
- インシデント報告
- コードコメント、docstring

目標:

- 正確、検索しやすい、再現できる
- 用語と表記が安定する
- 条件、例外、制限が明確になる

既定範囲: `minimal`

残すもの:

- 機能的な見出し、番号、箇条書き、表
- 専門用語、コマンド、コード
- 反復が検索性や曖昧性回避に役立つ場合の同一語
- 主語として適切なシステムやコンポーネント

減らすもの:

- 製品紹介のような美辞麗句
- 「革新的」「シームレス」など未定義の評価
- 現在の仕様に不要な執筆経緯
- 見出し直後の同義反復

禁止:

- 口語化のために技術的確度を下げる
- コードやパラメータを書き換える
- 箇条書きを一律に段落へ変える

## report

対象:

- 業務レポート
- 調査報告
- 提案書
- 学校課題

目標:

- 事実、観察、解釈、提案を区別する
- 根拠と結論の対応を明確にする
- 文書の提出要件を守る

既定範囲: `bounded`

残すもの:

- 節番号、図表番号、定義、引用形式
- 課題指定の構成
- 必要な中立性

減らすもの:

- 「重要である」のような根拠のない評価
- 同じ結論の再説明
- 形式だけの「今後の展望」

禁止:

- 筆者の立場を捏造する
- 学術的な慎重表現を断定へ変える
- 規定文字数を満たすために空話を作る

## academic

対象:

- 論文、研究計画
- 査読回答
- 学会要旨
- 文献レビュー

目標:

- 主張の範囲と不確実性を正確に保つ
- 引用と根拠を追跡できる
- 分野・投稿先の慣例に従う

既定範囲: `minimal`

残すもの:

- 受動態が慣例上必要な箇所
- ヘッジ、限定、反例、留保
- `本研究`、`本稿`、節番号など分野慣例
- 同じ専門語の反復

減らすもの:

- 内容を持たない重要性の強調
- 曖昧な権威づけ
- 根拠のない一般化
- 結果の後に付く過剰な意義づけ

禁止:

- 個人的な体験や感情を加える
- 伝聞を断定へ変える
- 引用を削って結論だけ残す
- 著者や研究室の文体を、一般的な「自然さ」で均す

## public-essay

対象:

- ブログ、note、ニュースレター
- SNS長文
- 評論、エッセイ
- 公開向け解説

目標:

- 書き手の判断が分かる
- 具体的な材料と主張が対応する
- 宣伝調、講演調、AI的な総括を減らす

既定範囲: `bounded`

許容:

- 元文にある一人称、ユーモア、毒、迷い
- 意図的な脱線や非対称な構成
- 一文だけの強調

減らすもの:

- 全方位に配慮した結果、判断が消えた段落
- 予定調和の導入、メリット3点、課題、未来への期待
- 「本質」「解像度」「手触り」などの密集
- 根拠のない大きな時代論

禁止:

- 原文にない意見や体験を足して「声」を作る
- すべての段落を崩し、読みづらさを人間味と呼ぶ

## fiction

対象:

- 小説、脚本
- キャラクター会話
- 創作文

目標:

- 視点、時制、語り手、人物の声を維持する
- 意図しない説明過多や均一なリズムだけを直す
- 作品固有の反復や比喩を残す

既定範囲: `minimal`

作者サンプルがある場合は必ず優先する。

一般文の規則から除外しやすいもの:

- ダッシュ、三点リーダー、断片文
- 反復、体言止め、主語省略
- 誇張、比喩、曖昧さ
- 語尾の偏りが人物性を作っている会話

禁止:

- 「具体性」のために設定や体験を追加する
- 文章を説明文へ均す
- 会話を標準語へ統一する
- ユーザーが校正だけを求めているのに展開を変更する
